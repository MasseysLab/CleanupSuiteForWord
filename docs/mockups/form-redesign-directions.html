CleanupSuite Form Directions

These are concept directions for making the VBA tool forms feel clearer, less Win95, and easier to move through without changing what Word UserForms can realistically do.

A. Structured Utility
Invisible Unicode Cleaner
One focused task. Calm hierarchy. Cleaner labels.
Mode: All invisible characters
Scope: Entire document / Selection
Options: NBSP, ZWSP, ZWNJ, ZWJ, BOM...
Preview only

Structured Utility

Best if you want something clearly improved but still familiar to Word users. Stronger typography, grouped sections, better button order, less visual clutter.

B. Guided Workflow
Punctuation Normalizer
Choose a mode, confirm scope, then run.
Step 1 of 3
1. Mode
2. Scope
3. Review
Recommended: All punctuation types

Guided Workflow

Best if the current forms feel counter-intuitive. Each tool becomes a short sequence: choose mode, choose scope, review preview behavior, then run.

C. Compact Modern Panel
Table Cleaner
Action Set
Context
Preview highlights only

Compact Modern Panel

Best if you want the most visual lift. Feels more like a current utility app, with denser panels, stronger grouping, and less dependence on plain checkbox stacks.

What I’m Reacting To In The Current Forms

The current suite is functional, but it leans on long vertical checkbox lists, tiny `?` help buttons, fixed-width forms, and repeated scope/preview patterns that make many tools feel more alike than they should. The redesign work should improve orientation, action order, and confidence before it tries to be flashy.

Recommendation

Start from B, then borrow from A. The biggest usability win is making each tool feel like a short guided task instead of a pile of controls. We can keep the implementation realistic for VBA while still making it feel much more intentional.
