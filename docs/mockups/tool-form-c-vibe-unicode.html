What changed from the current form

This version turns the form into a sequence of decisions instead of one undifferentiated control stack. It elevates recommended defaults, makes the scope state easier to read, treats custom options like a secondary panel, and makes the run area feel intentional rather than tacked onto the bottom.

Still realistic for VBA

This is more modern, but still plausible inside a Word UserForm if we simplify some visual effects. The biggest wins are layout, grouping, copy, button ordering, and reducing the “checkbox spreadsheet” feeling.
